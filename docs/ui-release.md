# آوین هانی — بازطراحی یکپارچهٔ A

## تغییرات
- زنبورهای کوچکِ پروازکننده حذف شدند. زنبور خطی در `src/components/nature-orbit.tsx` ثابت و قابل تعامل است.
- برگ‌ریزان CSS در هیرو و قصه؛ در reduced-motion خاموش می‌شود.
- راهنمای سه‌سؤالی در `/discover` و صفحهٔ اصلی؛ تعداد واقعی محصولات را از همان کاتالوگ می‌گیرد.
- مجله در `/journal` با آدرس مستقل، metadata، canonical و Article JSON-LD برای هر مطلب.
- sitemap شامل صفحات جدید است. هیچ دادهٔ محصول نمونه یا آمار فروش تأییدنشده‌ای اضافه نشده است.
- هدر و فوتر مشترک هستند. URL پیش‌نمایش روی خود سایت نوشته نمی‌شود.

## پنل و تصویر
- `/admin` همان پنل واقعی متصل به PostgreSQL است.
- اطلاعات مدیر فقط از محیط سرور؛ رمز حداقل ۱۲ کاراکتر. رمز یا کلید امضای عمومیِ پیش‌فرض نداریم.
- یک ADMIN_SECRET مستقل و تصادفی حداقل ۳۲ بایتی در VPS تولید و تنظیم کنید. در Git یا مرورگر قرار ندهید.
- پس از تغییر تنظیمات، redeploy/restart و ورود دوباره لازم است؛ نشست‌های قبلی باطل می‌شوند.
- ورود پس از POST، کوکی را با `/api/admin/session` بررسی می‌کند و سپس کامل به پنل می‌رود. در صورت مسدودبودن کوکی داخل iframe، پیام و لینک تب مستقل می‌دهد.
- محدودسازی تلاش ورود فعلاً در حافظهٔ همان پردازش است. برای چند instance، Redis یا محدودسازی reverse proxy نیاز است.
- تصاویر محصول توسط پنل در `public/uploads/` با نام تصادفی ثبت می‌شوند. مسیر `/uploads/[filename]` فایل جدید را بعد از start نیز سرو می‌کند.
- پوشهٔ uploads باید روی VPS volume پایدار و بک‌آپ جدا داشته باشد؛ redeploy نباید آن را پاک کند.
- نام فایلِ مشتری اهمیتی ندارد؛ نام محصول برای alt تصویر استفاده می‌شود. تصویر واقعی JPG/PNG/WebP و حداکثر ۳MB.
- نماد اینمادِ نهایی باید لینک اعتبارسنجی رسمی خودش را داشته باشد؛ جای عکس خالی به معنی صدور مجوز نیست.

## موارد خارج از این بازطراحی
- به گزینهٔ B مستقل در پلتفرم دسترسی نداریم و بازیابی آن ادعا نشده است.
- درگاه پرداخت واقعی هنوز فعال نیست؛ سفارش‌ها unpaid ثبت می‌شوند.
- Docker، SSL، بک‌آپ خارج سرور، مجوزها، اینماد و آزمون امنیتی پیش از انتشار جداگانه لازم‌اند.
- قبل از انتشار عمومی، محتوا/قیمت/ارسال با صاحب کسب‌وکار تأیید شود. تست‌ها جای ممیزی امنیتی را نمی‌گیرند.
